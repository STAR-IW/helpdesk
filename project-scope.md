

## Problem
Hundreds of support emails land in our inbox every day. Each one is triaged and answered
by an agent by hand, which is slow and tends to produce generic, templated replies.

## Solution
Build ticket management system - A support desk that leans on AI to sort incoming tickets, draft answers, and send them to
the right agent — so students hear back sooner and more personally, and agents spend their
time on the hard cases.

## Features
receive  support  emails and create tickets
auto-generate human-friendly response using knowledge base
ticket list with filtering and sorting
ticket debilitated view
AI-powered ticket classification
AI summaries
AI-suggested replies
User-Management(admin only )
Dashboard to view and manage all tickets

## Ticket Model
Status: open, resolved, closed
Category (single, one per ticket): general question, technical question, refund request

## Deployment & User Management
System is deployed with a single admin account.
Admin can create additional agent accounts.
